# NaturaSì Relex Category Optimizer (V2.3.0 BETA)
**Category Optimizer** è una Single-Page Application (SPA) avanzata, sviluppata per supportare gli Store Planner e i Category Manager nell'ottimizzazione dell'assortimento e nella parametrizzazione del software di Supply Chain **RELEX Solutions**.

## La Ricerca e il Pensiero alla Base del Progetto
Dietro questa applicazione si nasconde un profondo lavoro di ricerca e analisi sulle logiche della grande distribuzione e del mondo biologico. L'obiettivo principale è stato quello di tradurre le complesse formule matematiche di RELEX in "comportamenti intelligenti", capaci di adattarsi alla realtà quotidiana di un negozio NaturaSì.

## Utilizzo
L'applicazione è fruibile direttamente come Web App su GitHub Pages, accessibile in remoto da qualsiasi browser desktop moderno. Non è richiesta alcuna installazione.
1. Collegati all'indirizzo URL di GitHub Pages per accedere alla Web App.
2. Carica il file esportato da RELEX (formato `.xlsx`) tramite l'apposito tasto in alto a destra.
3. Seleziona le giornate di consegna per aggiornare in tempo reale la rete di calcolo del fabbisogno logistico.
4. Esplora i vari moduli (Setup, Diagnostica, Razionalizzazione, Sviluppo, Rollout) per ottenere i report filtrati.
5. Utilizza le funzioni di copia sincrona per incollare i parametri ottimizzati direttamente nella griglia di RELEX.
