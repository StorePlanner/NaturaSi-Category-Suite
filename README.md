<h2>📋 Overview</h2>
<p>
    The <strong>RELEX Category Suite (V72)</strong> is a specialized, web-based Control Tower and calculation engine designed for the NaturaSì Grocery Business Unit. It bridges the gap between Central Headquarters' inventory optimization goals and the Store Managers' visual merchandising needs.
</p>
<p>
    By processing raw Excel data, the suite mathematically converts real sales data, product dimensions, and supply chain constraints into perfectly calibrated ordering parameters (<strong>Presentation Minimums</strong> and <strong>Shelf Maximums</strong>) ready to be imported into RELEX Plain.
</p>

<h2>🚀 Key Features</h2>
<ul>
    <li><strong>Advanced Algorithmic Replenishment:</strong> Dynamically calculates optimal shelf parameters based on weekly sales, delivery schedules (including Sunday buffers), and physical packaging matrices.</li>
    <li><strong>Assortment Diagnostics (Diag):</strong> Automatically audits the store's inventory to flag anomalies such as dead stock, negative inventory, or missing "Must Have" products.</li>
    <li><strong>Delisting & Run-Out Management (Delist):</strong> Identifies slow-moving or discontinued items and applies "Capital Protection" rules.</li>
    <li><strong>Opportunity Gap (Opp):</strong> Scans the database to suggest new sub-category top-performers or mandatory items.</li>
    <li><strong>Booster Strategies:</strong> Features toggleable global modifiers (<em>High-Volume</em>, <em>Deep</em>, <em>Deep & Length</em>).</li>
    <li><strong>Store Label Generator:</strong> Instantly generates formatted <code>.TXT</code> files for shelf label printing systems (Frontalini).</li>
    <li><strong>Excel-like UI/UX:</strong> Data grid supporting column drag-selection, multi-sort, filtering, and native Excel export.</li>
    <li><strong>Dynamic Dark Mode:</strong> Adapts to OS/Browser theme preferences with manual override.</li>
</ul>

<h2>🛠️ Tech Stack</h2>
<ul>
    <li><strong>Frontend:</strong> Pure HTML5, CSS3, Vanilla JavaScript (ES6+).</li>
    <li><strong>Data Processing:</strong> SheetJS for client-side <code>.xlsx</code> parsing and exporting.</li>
    <li><strong>Architecture:</strong> 100% Client-side. Privacy-first by design (data never leaves the browser).</li>
</ul>
